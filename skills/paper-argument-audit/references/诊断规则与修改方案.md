# 诊断规则与修改方案

使用方法：先重建作者要从什么推出什么，再选相关规则。R编号用于追溯，不是扣分表。表中修改方法是将教材思路用于论文的设计，并非逐字引述或作者给出的统一标准答案。章页和案例ID可回到相应章节笔记定位。

## 问题、主张和支持层级

| 规则 | 可见症状及为何不足 | 可实施修法 | 来源 |
|---|---|---|---|
| R01 问题尚未建立 | 只有话题、变化、“研究较少”或重要性宣言，没有说清缺少什么理解，以及它妨碍了什么。 | 指明已知、未知及二者冲突/缺口；用可支持的认识后果说明为何值得解决。没有现实政策后果不自动构成错误。 | 第3章78—90；C06—C09 |
| R02 答案错位 | 引言问一个问题，结果回答另一个；证明问题存在后就宣布某方案有效。 | 让题目、研究问题、结果与结论对齐；区分问题诊断与方案论证。必要时缩减结尾承诺。 | 第3章100—108；C08、C10 |
| R03 主张空泛 | “有影响”“具有复杂性”等不说明对象、关系或可观察内容。 | 具体说明什么变化、在何范围、以何种方式；保留实际可检验而非装饰性限定。 | 第4章126—135；C12 |
| R04 强度越界 | “可能/部分/相关”被改成“必然/全部/决定”，或多重模糊词使作者不再承担任何判断。 | 将量词、情态与证据相匹配；明确保留的结论和不能推出的结论。谨慎措辞也不能救活本无支持的推理。 | 第4章128—136；C13 |
| R05 对象与尺度越界 | 研究少数地点、特定时期、单一功能或人群，却概括整个地区、所有阶段或全部功能。 | 把范围写回原结论；要推广就说明外推条件和相应资料，不能只加“具有代表性”。 | 第6章167—170；C03、C17、C49 |
| R06 功能与角色误读 | 仅凭“因为”判定论证，或把背景说明当缺五要素的失败论证；同一句的层级角色混乱。 | 结合上下文识别当前争议及该句用途；只检查它实际承担的支持任务。 | 第1章13—16、第2章44—50；C01、C04 |
| R07 支持层级断裂 | 数据跨越多个未证中间命题直达总主张；或某并行理由失效便宣布全部失败。 | 列出材料→局部判断→上位判断的链；逐环核查，说明断点影响范围，保留独立成立的支持。 | 第5章148—152、第14章375—378；C16、C43、C53 |
| R08 循环支持 | 理由只是将主张换词复述，或双方互相引用而无独立依据。 | 寻找与待证结论相独立的事实、原则或论证；不能靠增加同义句补足。语句能互换仅是提示，不足以判循环。 | 附录B461—462 |
| R09 争议前提被当事实 | 用尚待证实的标签或判断继续推论，未说明它为何可接受。 | 将前提提出来单独核对；若它不是无争议背景，补独立支持或条件化后续结论。 | 第2章53—54、第7章195—196；附录B462 |

## 根据、定义与结论力度

| 规则 | 可见症状及为何不足 | 可实施修法 | 来源 |
|---|---|---|---|
| R10 缺少连接根据 | 理由可能为真，仍看不出为何支持结论；增加同类数据不解决相关性。 | 试写隐含的一般原则并检验；确属共享常识时无需赘述。联系不成立时换理由或改结论。 | 第8章209—219；C23 |
| R11 根据超界或实例不符 | 一般原则有例外、比例失当，或具体情形不属于其条件/后果。 | 分别检查原则可靠性、范围、实例匹配及相关价值标准；限定原则，或说明当前例为何适用。社群接受不等于事实为真。 | 第8章218—223；C24、C27 |
| R12 结论被悄悄升级 | “不能禁止”变成“值得认可/应推广”，“不是人人必须”变成“人人不应”。 | 保留动词、量词和否定位置；强结论另作论证，或退回已支持的弱结论。 | 第7章194—195、第8章224—227；C21、C25 |
| R13 定义缺一项任务 | 只给词典标准，不说明为何适用；或有标准却没证明对象符合。 | 论证标准的适切性，再用对象特征检验匹配；边缘个案与专业标准按研究目的处理。 | 第10章253—270；C31 |
| R14 定义替代实际争论 | 定义“运动员”“好教育”等，便宣布某政策或评价必须成立。 | 把类别判断、价值标准与行动选择拆开；直接讨论决定需要的额外条件。 | 第10章257—259、265—267；C31、C32、C48 |
| R15 同词异义 | 同一术语在技术/日常、输入/结论、不同作者之间变了意思。 | 明确当前含义及操作化，统一用法；必要时保留不同含义并分别比较，不因同词就判相同命题。 | 第10章261—270；C33、C46—C48 |

## 材料到经验结论

| 规则 | 可见症状及为何不足 | 可实施修法 | 来源 |
|---|---|---|---|
| R16 证据报告被当证据本身 | 忽略观察、测量、图像、模型和转引的加工链；有图即认为无须解释。 | 定位原来源和产生方法，分开观察与推断，报告关键处理及不确定性。 | 第5章144—148、第6章170—177；C14、C19、C20 |
| R17 数字含义改变 | 数字抄对了，却换了事件、窗口、分母、参照组、单位或统计量；OR被叫成概率倍数。 | 按“谁、什么事件、何时、分母、指标、参照、调整与区间”核对。比例、百分点、相对变化及OR分别报告；不能从汇总比例恢复调整后的概率比。 | 第6章174—176；C19、C20、C49；OR区分为本次方法核查 |
| R18 比较条件不一致 | 不同年份或群体的比例用来推趋势，定义、取样或窗口不一致。 | 统一口径或说明不可比性；缺少可比数据时撤回趋势推断，而不是宣布相反趋势。 | 第6章169—170；C17、C50 |
| R19 覆盖与代表性不足 | 单一逸闻、便利样本或选择性回卷支持过宽总体判断。 | 限定样本范围；说明抽样、选择、遗漏及响应。少量案例仍可支持存在性、反例或机制探索，不按数量一票否决。 | 第6章167—178；C03、C44、C49 |
| R20 权威或利益关系代替核查 | 专家头衔替代相关研究；因资助关系就判结论错误，或忽视其可能影响。 | 检查相关专业性、可查依据及方法；把利益披露转成有针对性的审查，不转成真假的自动结论。 | 第6章172—173、附录B465—467；C18、C54 |
| R21 引文/图表缺少读法 | 材料堆积，作者未说明哪一特征支持哪项判断；解释被冒充为原话。 | 明确对比、模式、文本细节及其意义；保留作者解释与原材料的边界。解释本身超出材料时补根据或收窄。 | 第5章150—152；C15 |

## 因果、异议、方案与表达

| 规则 | 可见症状及为何不足 | 可实施修法 | 来源 |
|---|---|---|---|
| R22 关联被升级为因果 | 同期、前后、共变或调整回归被直接称为造成、机制已证或干预效果。 | 判断现有设计可支持到哪里；检验时间顺序、反向、共同原因、选择与测量等相关问题；无足够识别时写为关联或待检验解释。不是一律要求随机试验。 | 第9章241—248、第11章285—289；C29、C34、C49、C50 |
| R23 只验证偏好解释 | 多个同向例子重复支持初猜，却没有区分可信备选解释。 | 为关键竞争解释提出可区分预测，寻找不利材料；仅列出混杂可能不等于证明原结论为假。 | 第4章122—123、第9章243—248；C11、C30 |
| R24 推翻旧证据就确立新结论 | 一个论据无效，便宣布相反主张为真；未证伪就视为已证。 | 将“当前支持失效”“结论为假”“备选成立”分别处理，新主张另行举证。 | 第6章169—170、附录B462—463；C17、C50 |
| R25 误解概率和例外 | 以“有人没受到影响”否定概率效应；以“不是所有限制都有效”否定特定限制。 | 对齐命题是必然、概率还是存在；用能检验该命题的反例或比较。驳回一个无效反例不等于已证明效应存在。 | 第8章232—233、第11章300—301；C28、C37 |
| R26 干预链缺环 | 问题成因→某措施→中间结果→目标结果被连成既定效果，证据仅覆盖其中一段。 | 标明已测与未测环节；现有材料可保留机制假说，强效果主张需要直接结果和适当比较。 | 第3章101—102、第11章296—298；C10、C36、C51 |
| R27 方案未比较 | 由“需要保护”推出唯一工具，或只证明方案有益便声称最好/必须。 | 比较相关备选与组合、可行性、成本、副作用和目标；按任务深度检查，不强迫所有论文写五个故事。 | 第8章212—214、第11章296—298；C27、C36 |
| R28 类比越过关键差异 | 从另一行业、时代或情境的结果直接预测目标场景；指出任意差异就否定类比。 | 说明共同机制及与结论相关的差异；类比作为启发或有限支持，关键预测用目标资料检验。 | 第7章195—196、第11章300；C22、C37、C48 |
| R29 异议被歪曲或遗漏 | 只回应弱版本、攻击人、把多种立场压成两派；或局部片段没反驳就判整篇失败。 | 先公允复述与中心主张相关的强异议；区分真正反驳、可接受例外和不影响结论的分歧。 | 第7章189—205、附录B463—467；C21、C44 |
| R30 让步没有改变支持 | “尽管样本小，但问题广泛”“虽有局限，仍显然证明”，回应只是换词重说。 | 说明该局限为何不影响特定结论，提供独立支持；否则收窄主张、承认未解决处。 | 第2章52—54、第7章195—207；C03、C22 |
| R31 修辞改了事实或归属 | 选主语、强动词、比喻和情绪词时加入未证意图；把某人相信的因果改成作者断言。 | 保留事实、引文归属和证据强度；需要情绪/伦理理由时说明其与结论的关系。不能把拟人隐喻当机制。 | 第12章309—336、第13章348—360；C38—C42 |
| R32 结构连贯却支持不连贯 | 标题、段落、结论概念不一致，按资料来源流水排列；加转折和主题词掩盖实质断裂。 | 让段落承担明确任务，按支持关系安排；先修缺环再改衔接。被动语态、叙事、术语或晚现主张本身都不是错误。 | 第2章54—64、第14章365—378；C39、C43 |
| R33 选择性取证风险 | 只取确认资料、掩盖相反结果或预设唯一解释；读者无法检查关键选择。 | 分开资料收集与解释，披露与主张有关的不利证据，比较竞争解释；指出文本行为，不给作者诊断心理动机。 | 第9章243—248、附录B459—460；C30 |
| R34 来源边界不清 | 原话、转述、己见混合；同义替换掩盖来源；用书内教学例子代替领域文献。 | 恢复来源、具体位置和归属；独立转述而不改义。缺乏两份来源不直接判抄袭；具体引用格式按目标规范及版本核对。 | 第6章178—183、附录A445—458；C52 |

## 选择修法，避免用一句“补文献”应付

| 断点实际在哪里 | 优先动作 | 无法解决它的动作 |
|---|---|---|
| 已有材料，读者看不懂用途 | 增加具体读法和推理连接 | 再堆同类引文 |
| 一般原则有争议 | 说明原则、限制与支持，或撤回该前提 | 重复理由/提高语气 |
| 样本与外推不匹配 | 缩小对象/时期，或补覆盖资料 | 只加一句“具有普遍意义” |
| 因果识别不足 | 改为关联/假说，或补适当设计和分析 | 加“因此”“本质上” |
| 政策机制未检验 | 说明链条，比较方案，区分预测与结果 | 把现象问题描述得更严重 |
| 只是表达妨碍理解 | 调整角色、动作、信息顺序和指代 | 擅自更改指标、意图和结论 |

## 如何控制误报

严重程度以断点对中心主张的影响为准，不以触发几条规则计算。可用“影响中心结论”“需要补强的局部支持”“表达问题”“待上下文核对”等说明。

不接受这些机械标准：每段五要素、每篇至少三个理由、每项异议必须彻底反驳、所有根据必须明示、非随机研究不能谈任何因果、短样本没有价值、主动语态总优于被动语态、措辞适中便证明正确。

规范/价值主张不能按纯事实命题审查：公众偏好、伦理责任和苦难可能是相关理由；关键是说明采用的标准及其适用性。定义性或数学证明也不因缺少调查数据而不足。
