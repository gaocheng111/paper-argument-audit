# 第十二至十四章：表达、修辞与系统修订

页码为中文2022年版书页；对应PDF页加27。

## 第十二章：清晰的语言（309—347）

| 小节 | 作者强调与修改方法 |
|---|---|
| 简明写作的若干原则（310） | 主语呈现主要角色，动词呈现动作，尽早进入谓语，以熟悉信息承接新信息，将复杂新信息安排在较易处理的位置，维持话题连续。抽象术语若为受众熟悉，可作为角色；规则是有条件的建议。 |
| 简洁和生动（322） | 删重复、空词和不必要的词义拆解；简洁不等于最短。生动主要靠可理解的具体名词与动词，不靠形容词副词堆叠。根据学科、目的及受众选择语域，具体到读者无法识别的型号反而不能形成画面。 |
| 写作过程（331） | 先修改论证和组织，再改文风；检查开头、主语、动作、旧新信息与话题转换。主谓间长插入可移位或拆句；主动/被动按话题衔接选择。 |
| 课后习题（336） | 反思“清晰是否可能简化复杂现实”，比较专业人士面对普通读者的不同改写。不能把流畅度当真实性证明。 |
| 术语指南（337） | 区分分句、短语、独立/从属、词类、简单/完整主语及主动/被动。主要服务英语案例；中文不照搬时态、冠词、单复数或固定词数判据。 |
| 本章核心（345） | 六项原则加简洁和生动，配合诊断—修改；明确非铁律。 |

### C38：联邦党人的抽象句变成角色与动作

位置309—315页/PDF336—342。主张、破坏稳定、信念等名词链，改为联邦党人认为、民主破坏、集团牺牲等关系。

修法：恢复“谁主张什么、以什么理由”，压缩名词链。保留“某人相信”这一归属，不得改成作者已经证实的客观事实。

### C39：黑洞句的被动语态

位置335—336页/PDF362—363。前句已经引入黑洞时，被动句让黑洞继续作主语，比把漫长的坍缩过程置于句首更顺畅。

修法：按主题连续与信息结构决定语态，不一律主动化；研究方法和对象突出时，被动可以有效。

### C40：急诊案例与过度形容

位置325—330页/PDF352—357。抽象说明、具体情景和形容词副词加码的版本，分别体现距离、画面及过度修饰。马、铁锤、苹果等基本类别与专有品类的差别，说明生动取决于读者知识。

修法：必要时用真实可核查的具体例子解释概念，不为生动编造病例或场景；删除不增加信息的修饰，保留具有测量、限定或理论意义的形容词。

## 第十三章：语言的显性力量和隐性力量（348—364）

| 小节 | 作者强调与修改方法 |
|---|---|
| 唤起价值观和情绪（348） | 词汇选择和问题框架都含价值；客观语气不等于没有价值判断。先揭示选择，不把情感本身判作谬误。 |
| 如果情绪化语言破坏了理性思考（350） | 情绪不能替代推理；极端对立可能掩盖共存、程度、组合方案与第三选项；妖魔化对手会阻碍公平审查。 |
| 主语和视角（353） | 主语与动词决定叙述焦点和读者感受到的责任；手段作主语、抽象人格化、隐喻场景都可能帮助理解或隐藏能动性、引入无依据后果。 |
| 写作过程（360） | 检查情绪基调、主语焦点及抽象角色；写得快或慢可在不同阶段处理，不强制同一流程。 |
| 课后习题（361） | 分析广告价值、学校资助命名、语言和科学中的隐喻；并非要求写作完全没有隐喻。 |
| 本章核心（363） | 明确价值前提，检查是否用语言替代支持；六种改变视角的方法都须保持事实关系和责任判断透明。 |

### C41：市长、记者与捐款

位置353—356页/PDF380—383。不同主语突出记者盘问或市长行为；买/卖、教/学、数据“证明”等动词改变读者注意与归因。

修法：说明谁作判断、谁采取行动；不能因调主语而新增意图或因果。书中示例版本中新增“试图隐瞒”等内容，应另有证据，不能视作所有视角改写天然语义相同。

### C42：疾病、战争与自然选择的隐喻

位置357—360页/PDF384—387。把不受欢迎观点当传染病，可能暗示隔离；把警察行动当战争，可能暗示接受平民伤亡；自然选择被挪用来为商业行为辩护，超出解释用途。

修法：写出隐喻带来的推论，检验其是否另有依据；从“像某物”到“应按某物的规范处理”需要独立论证。书中关于自然、权利等价值判断不作为skill的通用公理。

## 第十四章：规划和修订对照清单（365—378）

| 小节 | 作者强调与修改方法 |
|---|---|
| 评估讨论或论文的问题清单（365） | 关心程度、潜在受众、答案与证据可得性；事实查找或简单回答可能不适合该教学论证作业。不能扩大为所有描述性研究或是非问题无价值。 |
| 论证清单（366） | 理由能否支持主张、排序能否理解、证据是否相关和充分。 |
| 完成连贯论文的10个步骤（366） | 找引言、问题、主张、结论、关键词、分节主张及证据、句首信息；这些标注服务诊断，不把圈词数或证据占比当通用阈值。 |
| 完整的问题清单（368） | 按读者→问题→主张→标题→引言→结论→主体→小节→证据→异议→根据→推理→意义→因果→语言检查，星标标识优先项。实用启示是按风险分配审查精力，不在每次回复中机械输出所有问题。 |
| 利用故事板，构思长论文（375） | 引言、结论、理由、根据与回应分为可移动的模块，允许空缺、重排及循环修改；是工作底稿，不等于最终论文章节结构。 |

### C43：长论文故事板

位置375—378页/PDF402—405。作者用两类理由模板区分“直接由证据支持”及“需要从属论证支持”的理由，再给根据和回应各自建立支持单元。

修法：先做一张简洁的支持关系图，标明哪些节点可由现有资料补齐，哪些需要作者研究或判断；不能因模板留空而虚构材料填满。

## 核心工作顺序

先判断文章要证明什么及支持是否成立，再决定是否重排、补证或限定，最后处理读者理解障碍与措辞。表达清楚可以暴露推理，也可以把坏推理包装得漂亮，所以每次重写后都要重新核对结论力度与证据关系。
