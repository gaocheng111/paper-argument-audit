# 第十五、十六章：完整文章对读

本文件分析书中实际收录的八篇文章，不把“被收录”视为教材作者赞同其全部立场。位置为中文2022年版书页；PDF页加27。下文的支持关系、局限和修改方案是本次分析，除明确写“文章承认”外，不冒充教材给出的标准答案。历史调查及评论不直接提供当前教育或健康建议。

## 第十五章：对待教与学的态度（381—420）

### C44：特罗塞特——讨论是在探究，还是在宣示立场？

《开放式讨论和批判性思维的障碍——对格林内尔学院的研究》，381—388页/PDF408—415。

| 小节 | 文章怎样论证 | 适合迁移的检查 |
|---|---|---|
| 认为讨论就是倡导（381） | 从多样性教育的目标与学生体验之间的落差出发，用访谈区分“表达已持有的立场”和“共同探索尚未确定的答案”。 | 论述提出问题后，是否允许证据改变答案？不能把敢发言等同于愿意检验观点。 |
| 寻求共识（383） | 用学生偏好与熟悉、相似的人讨论的回答，解释为何讨论常用于确认原有认识。 | 区分意见一致、感到舒适和论证可靠。讨论数量不直接代表讨论质量。 |
| 将个人经验视为唯一正当的知识来源（384） | 访谈显示学生重视经验，较少自发提及学术知识。 | 个体经验能证明某种经历存在，不能独自证明普遍频率，也不自动排除他人的资料。 |
| 不遭质疑的权利（385） | 区分拥有观点的权利与要求观点免受检验。 | 针对主张和理由提出异议，不把质疑转换为对人的否定。 |
| 影响（386） | 把上述倾向与校园不同群体之间难以对话联系起来。 | “能解释现象的机制”与“已识别的因果效应”分开。 |
| 偏激的相对主义（387） | 以“每人有每人的真理”分析免于论证的理由。 | 多种合理观点的存在，不推出所有支持同样充分。 |
| 让人舒适（387—388） | 对“让学生舒适”的目标提出修正：训练其面对不熟悉观点时仍能思考。 | 写作目标是可检验的理解，不是使所有读者毫无不适。 |

证据设计：研究说明跨数年的多批访谈、取样及不同问题的样本；不是同一批学生的纵向追踪。书中问法不同的百分比、单次访谈人数和受访者原话承担不同任务。

学到的方案：先界定教育目标，再观察实际互动方式，最后解释二者的落差。引用用于展示受访者如何理解“讨论”；数量用于描述回答分布。错误迁移是用一个生动引语证明“所有学生都如此”，或把不同年级的横截面差异当成同一学生随年龄变化的轨迹。修改时保留对象、问法、批次及证据类型，并将未直接检验的机制写成解释性判断。

### C45：埃德蒙森——有感染力的因果叙述仍需要证据

《论人文教育的用途》，389—397页/PDF416—424。

论证顺序：以学生评价日的亲历开场，提出“喜欢课程不等于受到思想上的挑战”；承认通常对激进理论的批评，再把主要解释转向消费文化。随后串联电视与广告、家长保护、就业压力、大学招生竞争，以及课程与校园服务的变化，最后提出人文教育应唤起持久的个人求知热情。

值得学习：用具体场景引出价值冲突；不是把学生直接当罪魁，而是追问制度与社会环境；提前回应“这是否只适用于作者所在学校”的疑问。文章也提到不同学校或个别教师的例外。

需要防守：本人课堂与同事印象不足以确立跨校代表性；1968至1993年人文学位占比变化不能独自证明消费主义造成该变化；多种原因串联成顺畅故事不等于各环节均已验证。结尾一些激烈措施具有评论性和修辞性，不能照抄成已证有效的政策。

修改方案：保留场景说明“问题可能是什么”，将总体频率与成因分别交给适当资料；把观察、机制假说和价值主张分开；提出政策时补充预期机制、成本与替代方案。若没有新增资料，应收窄范围和因果强度，而不是编造普遍统计。

### C46：珀纳尔——市场模型失效，不等于所有消费者保护都应停止

《学生消费主义走得太远了吗》，397—401页/PDF424—428。

| 小节 | 核心论证 |
|---|---|
| 我们今天置身何处（397） | 先承认消费者保护带来的合理收益，再追问是否继续扩大。 |
| 我们走得够远了吗（398） | 从“保护不足”转换到“市场类比能否继续承担指导作用”。 |
| 模型失效的地方（399） | 比较教育和常规商品交易的重要差异。 |
| 绩效问题（399） | 学习成果难以像一般商品那样直接衡量。 |
| 学位需要双方努力（399—400） | 学生参与影响结果，不能只向提供方归责。 |
| 没有质量保证（400） | 毕业、就业或满意不能在所有条件下获得保证。 |
| 大学不一定卖东西（400） | 学习不完全是成品交付。 |
| 利润问题（400—401） | 大学使命与逐利经营之间存在差异。 |

学到的方案：检验模型时比较与结论相关的机制，而不只找表面相似性；承认模型适用的一部分，再限定其失效范围。

错误方案：由“教育不是普通商品”直接推出“现有保护已经足够”或“进一步保护都不好”。修法：分别证明某项保护的收益、成本及使命影响，不将整套消费者权利一并否定。文中关于高校性质的历史和地域背景必须保留，不能扩展成所有私立或非营利机构的普遍事实。

### C47：麦克米兰与切尼——隐喻揭示问题，也会遮蔽问题

《作为顾客的学生：隐喻的含义及局限性》，401—415页/PDF428—442；参考文献主要在412—415页。

文章先提出语言影响组织认识与行动的前提，并承认顾客隐喻能提升回应与问责，随后提出四组风险，再给出替代的表达和关系安排。

| 小节 | 支持关系与边界 |
|---|---|
| 隐喻的局限性（403） | 把隐喻自身设为可检验对象，不只争论大学是否应该重视学生。 |
| 距离/组织关系（404—405） | 顾客容易被置于组织外部，而学生同时是参与者、成员和共同生产者。高学费即随时支配教师的例子，说明一种期待，不证明期待普遍存在。 |
| 教授自我推销与娱乐（405—406） | 说明满意、销售与教育挑战可能冲突；文本和概念分析不足以单独估计实际影响大小。 |
| 产品而非过程（406—407） | 以职业宣传等材料说明教育呈现方式的变化；学校宣传用语不等于已测得的学习后果。 |
| 个人主义与社群（408） | 分析竞争、个人权益与共同学习之间的张力。 |
| 替代说法（408—410） | 依次建议警惕语言、在适应与正直间权衡、尝试其他关系隐喻。 |
| 警惕语言（409） | 主动检查隐喻在组织交流中激活的期待。 |
| 灵活适应与正直（409） | 同时保留响应需求和教育判断。 |
| 其他方式（410） | 教练、社群、学习伙伴、学徒、批判性参与者等模型各有用途和限制。 |

文章承认可能过分强调对顾客隐喻的不满，也承认建议主要在修辞与沟通层面。skill 应保留这种自我限制。

修改方案：若作者主张隐喻“造成”组织后果，需要区分语言描述变化与组织行为变化，并补充二者联系的资料。换用“伙伴”也不能自动保证更好的教育结果。替代隐喻是帮助重想关系的工具，不是无需验证的干预。

### C48：斯文森——不同作者有时并没有在讨论同一种“顾客”

《客户和市场》，415—420页/PDF442—447。

文章先承认教师对迎合学生、削弱专业判断的担忧，再区分“购买产品”和“接受服务”。以成年人学生的需求和飞机客户参与设计的类比，说明回应使用者并不必然放弃质量控制。随后提出五种做法：以学习为中心、重视内容之外的能力、让学生参与目标、便利行政服务、倾听雇主等使用方。结尾同时保留实用教育与人文教育的价值。

优点：把对立口号拆成不同关系与不同决策权；明确“顾客”不等于“永远正确”。

局限：企业参与设计的成功类比不能单独证明每种大学改革都有效；成人在职学生的需要不能直接代表所有学生；行政服务响应与课程学术标准不可混为一谈。

对读方法：C46/C47质疑“整个教育成为可交付商品”，C48强调某些服务与参与安排。先对齐术语范围和决策对象，再判断是真冲突、部分相容还是事实分歧。不能只按赞成/反对“顾客”二分。

## 第十六章：纵酒、风险和公共健康（421—443；444为空白）

### C49：韦克斯勒等——把主张追溯到抽样、定义、分母和效应指标

《大学纵酒带来的健康和行为后果——针对美国140所院校学生所做的调查》，421—436页/PDF448—463。

| 段落/小节 | 论证任务 | 审查与迁移 |
|---|---|---|
| 摘要、背景（421—422） | 界定问题，并指出既有抽样与定义的不足。 | 摘要的因果或范围措辞必须与方法一致，不能只读摘要。 |
| 方法：抽样（423） | 说明院校筛选、参与率与学生抽取方式。 | 设计为代表性抽样，不等于实际响应样本天然无偏。 |
| 问卷、实施（424） | 说明自我报告、测量窗口、男女阈值、邮寄实施。 | 调查前两周的暴露与自学年开始的结果不属于同一窗口；定义只按本研究使用。 |
| 应答率（425） | 从寄出28,709份到调整后25,627人，再到17,592份回卷；比较早晚应答和部分未应答者。 | 排除、应答、各项分析分母分别记录。未发现差异不能证明任何未应答偏差都不存在。 |
| 数据分析（425—426） | 区分卡方比较、逻辑回归、加权/未加权，并列出调整变量。 | 有调整变量不等于排除所有混杂；参照组是喝酒但不纵酒者，不能写成完全不喝酒者。 |
| 学生特征、纵酒情况（426—429） | 描述构成、频率、差异和问题识别。 | 总回卷数和可分类人数不同；不要把子样本百分比移给全体学生。 |
| 表16-2/16-3（430—431） | 对健康问题和驾驶行为报告比例、调整后OR及区间。 | 分清比例、优势比、概率比与因果效应。 |
| 次级后果/表16-4（432） | 报告不同校园环境中非纵酒者的困扰。 | 校园层次暴露、个人层次结局及宿舍子样本各有范围。 |
| 讨论（433—436） | 解释结果、讨论定义与自报限制、提出重点。 | 观察关联和提出应关注的问题，不等于已经验证某项政策干预。 |

**经原页核对的指标案例：**432页表16-4最后一行，低、高纵酒程度院校的报告比例为62%和87%，调整后OR为4.1（95%CI 3.2—5.2）。同页正文将其说成概率大约四倍，这是不能照搬的表述。

更准确的报告为：高组报告比例比低组高25个百分点；按表中已四舍五入比例计算，比例之比约1.40；回归报告的调整后优势比为4.1。前两项未经调整，不能拿来替代调整后的结果。不能从这些数字直接断言校园纵酒环境产生了多大的因果效应。这一修订是本次方法核查，不是文章自承的限制。

430页表16-2同样标明调整后OR；“出现至少五项问题”的47%与3%，不意味着正文可以把25.10直接叫作发生概率的倍数。读表须连同参照组、区间、调整变量和脚注。

### C50：卡森——批评一种证据，不足以确立自己的整套替代解释

《消除纵酒》，436—440页/PDF463—467。

论证顺序：从学生对“纵酒”的理解与公共健康定义的落差切入；质疑趋势比较；将问题从饮酒量转向饮酒方式与社会规范；提出法律、期望和场景的解释；以校园规范宣传前后的变化支持替代办法。

其中关于不同年份女性样本不可比的批评，可与C17对照：一项资料是全体女性，一项是大一女性，不能直接判断趋势。但是，否定该比较，并不证明趋势一定相反或其他研究全部失效；随后引用专家的判断，也不自动解决证据不足。

文章以个人所见比较节庆与酒吧，用期望效应实验讨论行为，又以北伊利诺伊大学规范宣传及随后变化说明方案。这些材料各能支持一个有限环节，不能合成“所有危害都由文化预期而非酒精造成”。一次校园宣传前后变化，也没有单独排除同期变化和样本构成变化。

修改方案：逐一保留被批评的具体命题；替代解释提出可区分的预测；宣传效果写为观察到的变化，因果效果另需适当对照。对研究的局部有效质疑与评论作者的主张分开评估。

### C51：布鲁菲——改善中间环节，不等于已经改善最终结果

《不能以“纵酒”替代“学习社群”》，440—443页/PDF467—470。

论证顺序：由既有校园政策未解决问题，转向归属感与社交孤立；用个人经历说明学生为何加入社团；提出“课程学习社群→交朋友/归属感→降低纵酒动机→减少纵酒”的链条。

442页报告一项183名学生的研究：73%认为有助结交朋友，课程保留率73%，校平均59%。这些数字直接关联交友体验和保留，**没有直接测量干预是否减少纵酒**；与校平均比较也不自动解决参与选择差异。

文章在442—443页明确提出仍需研究协作式学习如何影响社交绝望，也承认它不大可能是普遍解法。这种限定值得保留。末尾较乐观的预测不能反过来充当实证结果。

修改方案：保留可行机制，把纵酒改善写成待检验的假说；未来检验应直接测量相关结果、比较适当群体并考虑选择和时间因素。不得润色成“研究证明学习社群降低纵酒”。

## 两组对读给核心功能的共同要求

1. 同一话题先对齐问题、定义、对象和结论层次，才判断作者间是否矛盾。
2. 每项证据只能支持它测到或解释到的环节；把中间结果换成终点，是常见越界。
3. 对旧解释的反例，不自动证明新解释；新方案承担自己的举证责任。
4. 教材收录的是可供分析的文章，其中既有可学的方案，也有值得质疑的跳步。
