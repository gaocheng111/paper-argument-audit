## 前言：使用模型的方式

位置：传授论证的艺术，PDF6—15；写给学生的话，PDF16—21；致谢PDF22—23。

| 部分 | 作者强调的点 | 对 skill 的约束 |
|---|---|---|
| 怎样使用本书（PDF6—8） | 概念讨论与写作过程相辅相成；分析要素不等于已经会写。练习可能没有唯一答案。 | 每个诊断必须连接实际修改；不能把我的练习解答标成作者标准答案。 |
| 与其他论证书的区别（PDF9—10） | 问题框架、读者、可信度及非正式推理贯穿全书；不是只学谬误名称。 | 优先定位问题与支持关系；读者异议不等于敌意。 |

| 写给学生：综述、观点与论证（PDF16—19） | 综述报告他人，个人意见表达立场，论证提供他人也能接受的支持。 | 综述、背景、方法描述本来可服务于全文，不因单段没有独立主张就判错。 |
| 经验与使用建议（PDF19—21） | 公式用于训练，熟练后应灵活使用；不同领域有不同期待。 | 固定格式、理由数量、字数比例、段首先后都不能替代支持充分性的判断。 |
| 致谢（PDF22—23） | 接受读者反馈可暴露作者自己看不见的问题。 | 我对论文的诊断也可被新材料和作者解释修正。 |

## 附录A：引用要恰如其分，避免无意抄袭（445—458）

| 小节 | 核心原则和应用 |
|---|---|
| 基本规则（445—446） | 区分借来的措辞、思想与方法；直接引用和自己的转述清楚分界；网络来源同样需说明。编者明确提醒英文引文规范不一定适用于中文出版物。 |
| 做好笔记（446—447） | 记录完整书目信息及具体位置，区分原话、转述、自己的分析，防止后来误认。 |
| 引用要谨慎（447—449） | 直接引用保留边界；转述改变表达组织而不偷换原义；思想和方法的借用也应归属清楚。 |
| 正确引用来源（449—450） | 引用使读者能回到原位置；选择适合目标读者和规范的格式。 |
| MLA（450—454） | 覆盖书籍、多人/多卷/多版本、译著、编辑合集、期刊/报刊/评论、影视和网络资料及正文定位。这里只提炼“来源类型决定字段、正文与书目相互对应”的思路。 |
| APA（454—458） | 覆盖相近来源类型以及作者年份体系、同年区分、页码和出版信息。保留来源辨识原则，不把书中版式例子当现行版本规范。 |

### C52：戏剧转述——同义替换不等于独立表达

447—449页/PDF474—476以“戏剧与观众关系”说明近似照抄与合格转述的差别。

学到的方案：先理解命题，再换一种结构准确复述，仍标明思想来源。错误方案是只改少量词语就认为不再需要归属。修改不应为了避免重复而改变原作者的限定和理由。若只看到近似文字、没有两份完整来源，指出相似和需要核对，不直接断定作者抄袭。

应用边界：附录关于重复使用短语可不再加引号/出处、五行分界、作者省略规则和具体MLA/APA字段，均有语境和版本限制。skill 不将其写成普适规范。用户要求规范核查时，按明确的目标刊物/学校和版本核对；本次未查询现行格式手册。

## 附录B：认知偏误和谬误（459—467）

### 认知偏误（459—460）

作者分成一般推理、语言和因果三组：信念与愿望过滤证据、过度自信、锚定最早答案、意识形态优先、单一解释；把词义当对象本质、定义争议替代行动争议、情绪措辞与误导比喻；偏好醒目/在场/异常原因，忽略常态、缺失条件、共同原因、多原因及情境。

检查的是文本中可指出的选择与推理，不据此给作者作心理诊断。“只引用支持材料”是可核对的行为；“作者因为某种动机而如此”则需要另外的证据。

### 基本推理错误（461—463）

| 书中项目 | 案例与机制 | 修改方案 |
|---|---|---|
| 不当结论（461） | 网络联系→国界消失→政府无事可做→政府消亡，多个桥梁未经支持。 | 把长链拆成子主张，逐段给根据与证据；不足时保留较近、较弱的结论。 |
| 循环论证（461—462） | “应有携枪自由，因为应有携枪权利”，理由重复待证命题。 | 找独立支持，不以改写同义句扩充理由。书中的互换检验是提示，不是循环成立的充分必要判据。 |
| 预设未定事实（462） | 先称某人为骗子，再以此否定其观点。 | 先证实相关事实；即使相关事实成立，也另查它能否影响当前论证。 |
| 诉诸无知（462—463） | 无人证明外星绑架为假，遂视其为真。 | 区分未证伪、可能、可信和已证；提出正面证据及可区分解释。 |
| 不愿面对后果（463） | 因不愿接受某种法律后果，就认定法律必定不是如此。 | 事实/解释问题与价值上的可取性分开。书中所用谬误名称不能替代对推理关系的分析。 |

### 依情境判断的修辞诉求（463—467）

| 书中项目 | 何时出现问题 | 不能误伤的合理情形 |
|---|---|---|
| 一致性/“你也一样”（463—464） | 对方曾有矛盾便拒绝其当前理由。 | 指出同一论证内部不相容，或要求解释相关标准为何不一致。 |
| 滑坡（464） | 没有机制和条件便宣称每步必然导致更坏下一步。 | 有证据的连锁后果、明确边界条件及概率性预测。 |
| 虚假两难（464—465） | 将可组合或另有替代的方案写成只能二选一。 | 已确立穷尽性和互斥性的分类。 |
| 比喻外推（465） | 把思想当疾病，直接套用隔离等措施。 | 用比喻帮助理解，并另外论证行动的正当性和有效性。 |
| 诉诸群众（465） | 以多数赞成代替事实真伪。 | 民主决策等场景中，公众偏好本来就是相关的规范性考虑；仍需说清决策标准。 |
| 诉诸权威（465—466） | 身份、声望与所论问题无相关专业性，或只以名气替代支持。 | 相关专业知识、可查依据、合理信任与分歧说明。 |
| 人身/关联攻击（466—467） | 因讨厌作者或资助者就宣布结论为假。 | 利益关系作为核查方法与披露的理由；不是错误的自动证明。 |
| 诉诸怜悯（467） | 用同情绕开与目标相关的证据。 | 苦难、尊严和伦理权衡本来构成规范性主张的理由。 |

### C53：网络与政府——短句也可能包含长串未证前提

461页/PDF488。每次“因此”都需要检验。即时联系不等于政治边界消失；没有边界也不等于公共治理无功能。好的修法不是加更多过渡词，而是缩短结论跨度，或对每一中间命题承担举证责任。

### C54：资助关系——怀疑的理由与否定的证明不同

466—467页/PDF493—494。书中枪支研究例承认资金可能影响研究，但明确区分“值得审慎检查”与“必定存在偏误”。skill 采用这一差别：核对设计、测量、报告选择与利益披露，不由资助关系直接裁定结论。

### 谬误名称的应用边界

464页把归谬法称为一种滑坡谬误，紧接着又讨论稻草人。经原页核对，确有此表述。skill 不采纳“归谬必然谬误”：从假设推导真正矛盾可以是有效证明；歪曲对方主张、缺乏推导便嘲讽其荒谬才需批评。463页的法律例也应先描述“从不希望的后果推断事实”的失误，而不机械贴“诉诸武力”标签。

这里修订的是本扫描中文本的可用规则；未对照英文原版，不能确定问题来自原文、翻译还是编辑。判断优先说清原句、支持关系和断裂位置，名称只作检索辅助。
