# 第九至十一章：推理、定义与因果

页码为中文2022年版书页；对应PDF页加27。教学例子均不直接当作当前研究事实。

## 第九章：推理的形式（241—250）

| 小节 | 思路与审查要点 |
|---|---|
| 3种推理形式（241） | 归纳从观察到概括；演绎使用一般原则处理具体情况；溯因提出暂定解释并与竞争解释比较。作者在242页注明其归纳/演绎定义与哲学家常用定义不同。审查时不能把“从一般到特殊”当严格有效性的充分条件。 |
| 溯因批判性思维的现实障碍（243） | 不用坚定信念替代证据；不随性积累无关数据；主动寻找否定材料、客观收集及解释、不排斥矛盾材料、克制过度自信、检查证据是否充分。 |
| 写作过程（248） | 想多个答案、设想什么会否定当前假说、用相反立场重看同一材料；也要预见读者会如何有选择地接受材料。 |
| 课后习题（249） | 借崇拜者和家人的反例，反思事实评价如何受情感影响。 |
| 本章核心（250） | 不同推理有不同风险：少量实例概括、机械套原则、锁定最早解释。 |

### C29：笔记本电脑与高分

位置241—244页/PDF268—271。作者先给出观察关联，继而提出电脑有助写作的解释，再提出勤奋、家庭资源与学习时间等竞争解释，追加不同选择条件下的比较。

诊断：更多同方向观察未必排除了竞争解释。修法：说清已有资料支持关联还是因果，提出能区分解释的设计或资料；不能仅凭排比句列出替代解释就声称已经控制。

### C30：头骨测量与确认偏误

位置245—246页/PDF272—273。作者转述古尔德对种子、铅弹测量差异的讨论，说明收集和解释可被预期影响，并明确提醒头骨→大脑→智力的链条缺支持。

修法：分开测量有效性与解释有效性，检查操作步骤是否可能随分组系统变化。该历史研究的真实争议未在此另行核实，不能把书中叙述当当前无争议科学结论。

## 第十章：关于意义的论证（252—278）

| 小节 | 思路与审查要点 |
|---|---|
| 一些术语（253） | 所指、类别、术语、特征、意义、标准、定义各有功能；术语意义比简短定义丰富。定义的存在并不自动解决对象归类。 |
| 意义和问题（257） | 先问定义要解决什么问题；警惕定义争论替代实践、价值或情感争论。 |
| 怎样进行有关意义的论证（259） | 两项任务：解释为什么接受该标准，证明对象特征符合标准。区分常见意义和权威技术意义；可用标准匹配、典型模型或结合二者。专业用语不能按论证方便随意改动。 |
| 词典为何不能解决意义论证（265，位于上一大节之内） | 词典标准不穷尽用法；标准自身仍需解释；类别边缘与技术适用需结合目的、领域知识和证据。 |
| 写作过程（270） | 识别真正有争议的关键词，选择标准/模型/类比；若定义掩盖行动争议，直接比较措施及后果。避免无用的词典开头和无边界地重定义。 |
| 课后习题（273） | 分析相近词、命名的社会后果、模糊边界及不同组织定义目的。术语选择不只是同义词替换。 |
| 本章核心（275） | 接受标准、描述对象、证明匹配；避免定义的替代论证及滥用词典权威。 |

### C31：竞技舞蹈、运动员与奥运项目

位置265—267页/PDF292—294。词典对力量、敏捷或技能的宽泛描述，可把许多常识上不当运动员的人也包进来；冰舞的历史分类另有背景。

修法：先说明相关标准及为何用于该研究，再逐一验证对象。即使属于“运动”，也不自动满足“应列奥运项目”的全部条件。防止把分类结论当行动结论的充分理由。

### C32：《泰坦尼克号》的杰作与商业炒作

位置258—259页/PDF285—286。两方表面争类别，实际以不同评价标准表达喜恶；即使认可商业属性，也可能继续认为作品伟大。

修法：把分类、价值标准与情感评价分开，明确真正争议；不要只重写定义以宣布胜出。

### C33：理论、风险、自然选择

位置261、264—265、269—270页/PDF288、291—292、296—297。科学“理论”与日常猜测不同；风险的专业概率框架与公众的控制、选择等关注不同；达尔文通过回应误读解释“选择”的非有意含义。

修法：同一术语在各段保持同一含义；跨受众明确解释差异；类比用来解释概念，不把拟人说法当因果机制。风险等案例中的专业标准仅为书中历史材料，不提供现行诊断或监管标准。

## 第十一章：有关原因的论证（279—306）

| 小节 | 思路与审查要点 |
|---|---|
| 繁多得不可思议的原因（279） | 原因有无限回溯、细分、背景条件和缺失条件；不能把最醒目的单一因素当全部解释。 |
| 寻找相关原因（280） | 区分近因/远因、发生/未发生、异常/惯常，防止偏好解释及“大结果必有大原因”。实践问题关注可干预点，概念问题关注所研究的解释层次。 |
| 系统地分析原因（285） | 异同与共变可用于提出、比较候选解释；创建对照、考虑反向关系、共同原因、相互作用及独特事件。这里是入门启发，不能代替研究设计。 |
| 因果关系和个人责任（290） | 引起结果与值得赞责不等同。另查选择自由、可预见性、动机、同情境通常行为及环境帮助/阻碍；知识、情感、政治和文化可能影响归因。 |
| 写作过程（296） | 区分问题成因、干预机制、实施过程、成本副作用、替代方案五项问题；叙述要有足够细节，但按时间排列不等于证明因果。类比、原则及数据可帮助解释，各需检查适用性。 |
| 课后习题（304） | 自由意志与条件、未发生事件何时算原因，训练识别归因框架。 |
| 本章核心（305） | 回顾原因选择及五项政策问题；概括中关于相关性和因果的表述须与289页的限制一并阅读。 |

### C34：笔记本电脑的2×2表及使用年限

位置285—289页/PDF312—316。表格要求同时看有/无候选原因与有/无结果，共变再比较程度；作者随后明确指出富裕学区等共同原因、反向选择和复合效应。

修法：保留四种组合，核对分母及样本；区分效应大小、统计不确定性和因果识别。列联表和剂量趋势不足以单独证明因果。

### C35：落水儿童、教师、救援者与护栏

位置290—295页/PDF317—322。多人可与结果有关，但不同角色关注的责任和目标不同；作者再用动机、预见、选择及环境解释责任判断。

修法：先证明行为/遗漏与结果的联系，再提出责任标准；不从坏结果倒推当事人有恶意，不把改善环境等同于解除全部个人责任。

### C36：改进教学评价的五项叙述

位置296—298页/PDF323—325。说明旧机制为何造成问题、新评价如何改善、如何实施、成本是否适当、与研讨班等替代方案相比怎样。作者明确提醒不要非此即彼。

修法：为政策建议补上“措施→中间环节→目标结果”，比较组合方案与替代方案。只证明存在问题，不足以证明所选方案最好。

### C37：纵酒禁令的类比与反类比；暴力媒体的概率效应

位置300—301页/PDF327—328。毒品禁令与历史禁酒被用于相反预测，说明类比可以互相竞争。媒体与吸烟的类比回应“大多数人无害，所以没有任何影响”。

修法：比较目标情境与来源情境的关键机制。概率性影响不要求人人出现结果，但反驳“必须人人出现”也不能单独证明当前效应存在。

## 必须保留的方法边界

这些是对教材应用的审慎修订，不是对原书的逐字重复：

1. 书页285把2×2百分比比较称为“方差分析”；skill 使用“列联表/分组比较”来描述这里的实际操作，不等同于通常所指的ANOVA。
2. 书页305的因果概括过强。结合289页的共同原因、反向关系和对照限制，skill 不采用“相关显著或比例差大就证明因果”的规则。
3. 书页247的“按定义一半驾驶者低于平均水平”不能作为一般数学规则；均值不等于中位数。该页关于过度自信的教育目的不需要依赖这个错误前提。
4. 书页242采用宽泛的演绎说法，并自行声明与哲学定义不同。skill 不把统计性预期当作形式上必然的结论。
5. 书页296正文说至少两种、至多五种叙述，305—306页章末却写至少五个。skill 按当前主张涉及的问题选择检查项，不强迫每篇文章写五个故事。
