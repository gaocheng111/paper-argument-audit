# 期刊语料的可核查记录

manifest为UTF-8 JSON对象，路径相对于manifest所在目录。仅在真实资料齐备后写记录，不生成30条虚构样本。字段如下：

- `journal`、`article_type`、`profile_path`：非空字符串，画像文件路径可回查。
- `official_guidelines`：对象数组，每项有`url`、`accessed`（日期）、`notes`（真实记录），作为官方要求来源。
- `articles`：真实论文对象数组。每项需有`id`、`title`、`journal`、`article_type`、`year`、`doi`（无DOI可为空）、`source_url`、`fulltext_path`、`fulltext_sha256`、`text_path`、`card_path`、`read_status`。
- `read_status`只有`complete`计入完整阅读；`candidate`、`partial`、`unavailable`保留进度但不计入。PDF先提取为UTF-8`text_path`，按页做定位，避免多栏阅读顺序错误。
- 每篇`sections`为对象，键为`abstract`、`introduction`、`literature`、`methods`、`results`、`discussion`、`conclusion`。每项有`status`（`present`/`integrated`/`absent`/`not_applicable`）、`observation`。前两种另需`locator`和`anchor`：可回查页/节、提取文本中能精确找到的短文本，不要求整段复制。
- 每篇`argument_map`为非空文字，公平说明全文主要支持关系；`boundary_note`为核查限制或明确未见断点的范围说明。
- 画像每项惯例保留支持ID、可观察分母、反例ID、适用条件与置信说明。频率计算从真实卡片产生，不能由脚本补写。

调用：`python -X utf8 scripts/check_journal_corpus.py <manifest.json>`。输出是结构门槛结果，真实理解仍由研读卡和回查负责；不能将`ready=true`写成期刊接受率或写作质量认证。
