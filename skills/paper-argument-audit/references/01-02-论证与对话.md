# 第一、二章：论证的性质与对话结构

来源：《论证的艺术》原书第3版，中文2022年版。正文书页加27为本文件对应PDF页。以下为转述与应用设计，不是作者原文。

## 第一章：论证、批判性思维和理性（书页3—34）

| 小节 | 作者的论证路径、强调点及可迁移做法 |
|---|---|
| 论证的定义（3） | 将“论证即争胜”的战斗隐喻换成合作式批判性思考；成功也可以是澄清分歧，不能把是否迫使对方同意当唯一评价指标。 |
| 论证的益处（5） | 从检验别人转向检验自己；检查反证、其他解释、假设及矛盾。区分“有事实/知道规则”与能反思推理质量。随后把这种实践放到社群、专业研究和公共讨论中。 |
| 伪论证的定义（13） | 谈判、宣传、胁迫可能有效，却不等于以双方愿意检验的理由求解。区分论证与解释、故事、图像；三者可嵌入论证，但不能仅因出现“因为”或一个生动故事就判定论证充分。情感与人格并非一概排除，不能代替支持。 |
| 写作过程（17） | 电梯故事先说问题、重要性、暂定答案及证据方向；识别真实或规定的读者。略读搭框架之后再细读并提问；先有粗略计划，但起草与修改循环，不等材料齐全才动笔。 |
| 课后习题（26） | 通过事实共识与结论分歧、论证成功却未达成一致、故事与隐喻等问题检验概念边界。是练习，不是作者已经给出的实证答案。 |
| 写作重点（30） | 对学校、雇主、组织等不同受众，练习说明问题、后果、方案、障碍与证据；广告练习要求把理性与情感诉求分开分析。 |
| 本章核心（34） | 先理解引发论证的问题和读者需要，再提出候选答案与理由；写得快或慢都可以，但须留出检验和修改空间。 |

### 案例 C01：同一句“我要回家，因为太累且不断出错”

- 位置：书页14—15，PDF41—42。
- 作者安排：对方已经接受该回家时，这句话在解释；对方要求继续留下时，相同内容在支持有争议的决定。
- 学到的判断：论证角色依赖交际目的和上下文，不能按连接词机械分类。
- 修改方案：先确定作者是解释已接受的现象，还是证明一个待接受的判断；解释段不能因没有反驳部分就被判“缺少完整论证”。

### 案例 C02：故事与饥饿儿童图像

- 位置：书页15—16，PDF42—43。
- 作者安排：故事让人期待后续，图像调动情绪；读者仍需知道具体主张和支持理由。图像可以呈现证据。
- 失败机制：把“令人感动/可信的叙述”误当“对一般结论的充分支持”。
- 修改方案：说明故事或图像支持哪个判断；一般性主张需要相称证据。不得把本书的讨论扩大为“图像和叙事没有研究价值”。

## 第二章：论证是文明的对话（书页35—76）

| 小节 | 作者的论证路径、强调点及可迁移做法 |
|---|---|
| 论证的5类问题（35） | 主张、理由、证据、承认与回应、根据；这是读者提问的功能框架，不是每段必须填满的五格表。 |
| 文明对话中论证的根源（37） | 学生、同学和教师的追问逐步暴露取样、概念、类比代价及推理原则；不同意不等于攻击。 |
| 综述：为论证建模（44） | 主张与理由按相对支持关系区分；同一句可在一个层次当主张、另一个层次当理由。证据需可指认，而非临时想出。 |
| 撰写书面论证（50） | 默认可按问题、主张、理由和证据组织；异议及根据放在读者需要之处。读者不明白材料用途时才需背景解释，不堆砌无关背景。 |
| 充实你的论证（53） | 简单模型不是充分论证。理由、根据和回应也可能是从属主张，需要自己的支持。 |
| 写作过程（54） | 从通用草图开始，按受众调整；慎用机械五段式、发现过程流水账、按来源逐篇概述、两对象各写一半。故事板把理由、证据、异议和回应关联；主张常宜早现，但可晚现并预告关键主题。引言和结论须相互对照。 |
| 课后习题（64） | 要求分析回避问题、可信度、语境和工作/学校论证差异；不预设所有场景必须有相同数量的证据。 |
| 写作重点（67） | 变换受众、立场及基本原则；让自己为不同立场寻找最佳支持，以练习公平重建。 |
| 本章核心（74） | 证据和根据是两个锚点；五类问题可以递归展开为从属论证。 |

### 案例 C03：学生付费，所以学生是顾客

- 位置：书页37—44、52—54，PDF64—71、79—81。
- 论证：学生认为关注不足，举一栋楼一层办公室开放时间为证据，并以“付费购买服务就成为顾客”为根据。
- 作者明确追问：样本是否覆盖学校；教育与服务的类比能走多远；顾客待遇是否意味着购买学位；未经证明的根据为什么成立；承认小样本后说“仍是广泛问题”，回应本身有何支持。
- 修改方案：分别处理证据覆盖、关键概念和推理前提；可缩小到有资料支持的服务事项，或者补充更广泛证据与原则论证。不能用“当然样本有限，但……”自动消除缺陷。
- 正反关系：书中改写后的完整形式仍被作者批评不充分。不能把“示范结构”标为“所有判断均已证实”。

### 案例 C04：诺贝尔奖研究员教授本科课程

- 位置：书页47—50，PDF74—77。
- 作者安排：先区分“教学使命优先”的主张、“优秀研究员任教”的理由和具体任教事实；再加入“研究好不等于教得好”的异议、教学评估与获奖者信息，并呈现连接理由和主张的一般原则。
- 学到的判断：不把有名教师任教直接等同于整个学校教学质量一流；新加的回应和一般原则也要接受检验。
- 修改方案：按需要核查教学表现、覆盖范围及“投入体现优先级”的适用性。此人物为书中虚构教学例子，不能当实证引文。

### 案例 C05：两篇饮酒与通知家长的学生范文

- 位置：书页70—74，PDF97—101。
- 设计：先排除语言错误干扰，再比较两篇文章如何处理隐私、家长权利、政策有效性及例外。
- 第一篇可见风险：从广泛接触酒精跳到政策无效，以校长本人饮酒回应政策，可能没有回答对方的安全理由。
- 第二篇可见改进：明确讨论权利程度、家长视角和住校/非住校等例外；同时“付钱便有知情权”和自杀干预类比仍需独立检查。
- 归属说明：本书要求读者比较，并未在该练习中逐条裁定以上错误；上述具体风险为本次分析，不冒充作者答案。文笔流畅、承认异议较多，不保证结论正确。

## 对 skill 的直接约束

1. 先复述作者最强、最合理的论证，再指出缺陷；不以模型自己的立场代替审查。
2. 每个问题都给出原文位置、支持关系、缺陷机制及可行修法。
3. 区分缺证据、缺推理桥梁和表达不清：三种问题需要不同修改。
4. 不把无争议前提必须显写、主张必须句首、每段必须回应异议当硬规定。
