# 第六至八章：证据质量、异议回应与根据

页码为中文2022年版书页；对应PDF页加27。作者观点和本次应用性分析分开标明。

## 第六章：报告证据（165—187）

| 小节 | 作者的思路与用于修改的判断 |
|---|---|
| 权衡证据的分量（165） | 证据类型取决于问题和学科；充分程度还与主张强度、受众原有信念及行动代价相关。不是只找手边最容易获取的材料。 |
| 制订寻找证据的计划（167） | 先说明要检验什么、需要哪类材料、可能从哪里获得，再搜集；不是漫无目的增加信息。 |
| 证据质量的四大准则（167） | 准确、精确、代表、可靠。可靠性含时效、声誉、公正、来源层级；声誉不能替代专业范围，利益冲突应查明而非直接证明数据为假。 |
| 可信的证据报告（170） | 逐类讨论记忆、逸闻、权威报告、图像录音和数字展示。记忆可重构；逸闻可说明但不足以独自支持广泛推断；权威重复判断不等于报告证据；数字及图像依赖定义、口径、取景与表示。 |
| 强烈的怀疑立场（177） | 可修正、非绝对确定的证据并不等于什么都不可信。拒绝一切证据的无限追问不应成为审查标准。 |
| 写作过程（178） | 类型与主张匹配、权衡成本、选择来源、试采样、盘点证据。笔记区分原话、转述和自己的推断，记录来源与上下文；观察及时记录并说明方法，报告不利数据。 |
| 课后习题（184） | 比较办公时间原始记录、平均数和“时间不足”的判断；测试何种场合应要求更强的核查。 |
| 写作重点（185） | 关于事实、叙述与真相的讨论任务，不是取消事实核查的授权。 |
| 本章核心（186） | 证据和根据是锚点；把对材料可靠性的合理检验与不可终止的怀疑区分开。 |

### C17：女大学生醉酒比例的两次调查

位置169—170页/PDF196—197。卡森质疑一项趋势比较，指出先后调查分别涵盖所有女大学生与仅大一女生；随后却用资深专家的一句话支持自己的总体趋势判断。

作者提问的两层：原比较存在代表性/可比性问题，并不能自动证明“完全没有上升”；专家说趋势平坦也应展示所依据材料。修法：统一人群、定义与调查条件；已有比较无效时撤回该证据，不直接宣布相反命题成立。

### C18：教师是否阅读评价与教学改进

位置172—173页/PDF199—200。先只引用“反思者受益”的权威判断，改写再报告研究对象及后续表现，说明证据应超出意见重复。

修法：请求原研究的设计、比较条件和结果。书中改写说明如何补证，不足以单靠这个简短描述确认因果识别；本草案不把示例中的数字当已核实事实。

### C19：同一公司数据的不同图表

位置174—176页/PDF201—203。毛收入、成本、净利润及百分比等表示，会凸显不同信息。

修法：说明研究实际比较的是规模、增量、利润率还是其他指标；读图时保留单位和分母，必要时同时给出相互补充的表示。某一种图更有说服力并不等于它更适合当前问题。

### C20：患病人数转成年度死亡人数

位置176页/PDF203。转引中将某病患者数量改成“每年死于该病”的数量；数字保留，但对象、事件和时间单位改变。

修法：逐项核对“数的是什么、谁、何时、单位、分母和原出处”；准确复制数字不等于准确使用数据。

## 第七章：承认和回应（188—207）

| 小节 | 作者的思路与用于修改的判断 |
|---|---|
| 他人观点的重要性（189） | 不仅“两边”，还可能有多种问题框架与证据标准；主动寻找最强替代观点，而不是仅以读者愚蠢解释分歧。 |
| 对问题及其解决方法的疑问（191） | 问题是否存在、定义是否恰当、主张范围、替代方案、成本和新问题。 |
| 对论证支持证据的疑问（191） | 区分数量不足、事实错误、不够精确、过时、不代表目标、来源与操作化不合适；再审查根据的真实、范围、适用与社群恰当性。 |
| 关于一致性的问题（193） | 同一原则应解释相似情况；存在区分时给出相关区别及支持，而不是为了自身方便挑选使用。 |
| 用附加论证加以回应（195） | 回应需要自己的理由、证据、根据；重大反驳可形成从属论证。承认合理局限不等于整个论证失败，也不必无限回应。 |
| 写作过程（198） | 从他人的承认看领域语境，记录支持及相反材料；草拟核心后再系统检查异议，避免瘫痪。重要且全局相关的异议宜早处理，局部异议在相关处处理；可按排除方案组织，但需避免漏掉可行备选。 |
| 课后习题（204） | 讨论无法反驳的强异议、旧稿漏掉的不同观点；添加过多后再删，显示这是一项训练而非最终篇幅要求。 |
| 写作重点（205） | 改变受众后重新考虑回应；同一事实在不同立场中需要不同解释。 |
| 本章核心（206） | 论证可存在内在错误，也可本身成立但不完整；两者分开诊断。 |

### C21：不是任何人都不该分专业

位置194—195页/PDF221—222。通识教育论者承认缩小专业规模的替代方案、特定学生的专业需求，再把主张限定为不应强迫所有人分专业。

修法：区分“所有人必须X”的否定与“所有人必须不X”；找到不影响核心结论的例外，而不是让步后仍重复绝对主张。

### C22：教学评估公开—专业人士改进—大学教师

位置195—196页/PDF222—223。回应先借医院等行业，再遇到终身教职和非营利大学的差异，作者示范继续支持回应或坦承局限。

修法：核对类比与作用机制；不能因为另一行业有效就判本行业必然有效，也不能只指出差异而不解释该差异为何改变结果。

## 第八章：为主张和理由提供根据（208—238）

| 小节 | 作者的思路与用于修改的判断 |
|---|---|
| 理由背后的推理（209） | 理由真实和理由相关是两回事；跨专业或文化受众可能不共享推理前提。 |
| 根据是什么样的（210） | 一般条件与一般后果，可显可隐。“每当X，那么Y”用于把前提显化并寻找例外，不要求论文每段这样写。 |
| 根据如何运作（212） | 检查一般原则、具体理由和具体主张的对应；原则成立不等于具体应用成立。 |
| 判断书面论证何时使用根据（214） | 当联系非显然、专业背景或价值前提不同；另可用于强调或建立共识，但不能把强化修辞当作增加证据。 |
| 怎样检验根据（218） | 真不真、限制在哪里、能否涵盖理由和结论、是否适合目标社群。原则争议需要独立支持，不靠重复断言。 |
| 区分理由与根据（223） | 具体支持与一般连接原则功能不同；日常语言可都叫理由，但审查时要分清。 |
| 回顾：测试案例（224） | 说唱例子逐步改变原则、理由类别和结论力度，展示同一论证可能在不同连接点失败。 |
| 为证据提供根据（228） | 不仅理由→主张，材料→理由也可能需要解释；必须说明引文或图表的哪种特征允许该判断。 |
| 通过证据论证和通过根据论证（229） | 原则推出的经验判断也需接受事实检验；笼统的行为补偿原则不能变成无需调查的万能政策论证。 |
| 写作过程（230） | 找关键假设，安排位置；类比可以暗示原则，但对比本身、对应关系及隐含前提均应检查。 |
| 课后习题（233） | 调整原则范围，区分表面共识与真正共享的理由/根据，说明同结论可由不同推理到达。 |
| 写作重点（236） | 谚语展示文化中的推理预期；不能仅凭一条谚语概括整个文化，也不能把相似谚语直接视为文化完全相同。 |
| 本章核心（237） | 区分未明示、不成立、太宽泛、不适用、受众不共享等不同缺陷。 |

### C23：不确定学费值不值，所以应增加写作导师

位置218—219页/PDF245—246。作者将隐含原则推广为“凡不能确定物有所值，就有权获得更多服务”，使原推理的可疑处显现。

修法：分别说明现有写作支持不足的证据、导师为什么能解决该不足、资源配置的理由。重复学费涨幅不能补上这一连接。

### C24：洗车要求粉刷房子，或要求协助作弊

位置221—222页/PDF248—249。前者检验回报原则的比例、时限和能力边界；后者检验“作弊”是否属于合适的善意回报。

修法：区分原则需限定与具体实例不属于原则；不能笼统都称“缺乏证据”。

### C25：容忍说唱是否等于承认为正当艺术

位置224—227页/PDF251—254。反对审查的原则不必然支持对艺术地位的积极认可；扩大“艺术”到“表达”也会改变前提的可接受性。

修法：保留结论中的动词与强度，分别审查“不禁止”“可容忍”“可认可”“应推广”，不把它们互换。可补强原则、收缩主张或另作论证。

### C26：针头交换与降低风险的原则

位置229页/PDF256。作者对比基于调查报告与基于“风险降低就鼓励参与”原则的论证，指出后者可被套用到安全带等多种情境。

修法：将经验前提作为待检验命题，不把“常识原则”当当前政策有效性的实证结论；调查是否足以推因果还需另审。例子不构成当前公共卫生建议。

### C27：林中独居与保护手段

位置212—214页/PDF239—241。作者用一般原则、条件和实例解释根据，随后以当事人不会用枪或不接受该保护形式，展示应用如何失败。

应用性补充：即使同意“需要保护”，也不能只因某工具属于保护手段，就证明该工具必要或最优。应比较可行替代与条件，防止从“某类需求”直接推出“唯一具体方案”。这是本草案的进一步分析，不冒充作者在该处明确提出的形式逻辑结论。

### C28：英语食物词与法语来源；电影年龄限制类比

位置215、232—233页/PDF242、259—260。前例呈现专业读者熟悉而公众未必知道的背景原则；后例以烟酒限制反驳“有规避就不应设限制”。

修法：补充真正需要的背景；将“不完美执行不等于完全无效”与“本方案确实有效”分开。历史词源或监管事实若用于研究，须另查原始材料，不能引用教学例子当现实依据。

## 不应固化的表面指标

承认异议的次数、引用数量、权威头衔、是否使用“每当”以及反方有没有被完全说服，均不单独决定论证质量。
