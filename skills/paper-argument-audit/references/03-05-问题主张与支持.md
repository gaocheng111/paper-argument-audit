# 第三至五章：问题、主张与支持关系

页码为中文2022年版书页；对应PDF页加27。除明确标注外，均为对作者说明的转述。修改方法为面向论文的应用设计。

## 第三章：激发你的论证（77—118）

| 小节 | 论证思路、作者强调与修改启示 |
|---|---|
| 两种问题（78） | 实践问题须改变或支持行动；概念问题须改变理解。先辨问题类型，再评答案是否匹配。 |
| 实践和概念性问题怎样激发论证（79） | 两者都有状况与后果，但概念问题的直接后果是更重要的认识缺口。不能把话题、个人兴趣或抽象重要性当作已经建立的问题。也不强迫纯研究承诺立即改善现实。 |
| 在引言中为问题建立框架（85） | 先确定状况与代价，再考虑共同基础及答案。相同状况可能对应不同代价和方案；区分消除成因与缓解代价。应用研究须说明知识缺口如何连到行动所需的理解。前奏应引入问题的关键概念，不仅为吸睛。 |
| 结论（100） | 可重述主张、解释意义、指出下一问题、呼应前奏；并非要求每篇写全四项。结尾提到方案不等于正文已经证明其有效。 |
| 引言和结论都是思考的方式（101） | 这些安排帮助检验问题与答案，而非固定段落模板。区分“证明问题存在”的论证和“证明某方案可解决问题”的论证。 |
| 写作过程（103） | 主题→缩小范围→提问→说明问题。用构成、过程、系统、历史、性质提问；在研究中逐步明确意义。检查引言、正文、结论的关键概念是否一致，用关键概念改进标题。 |
| 课后习题（109） | 比较纯研究价值、不同受众的代价，以及只介绍阅读教学法与实际提出教学问题的引言。提供练习材料，不是所有提问都有书中标准答案。 |
| 写作重点（112） | 政策调查、校友经验、风险运动等任务改变读者和目的；有的明确要求说明议题而不要求投票建议，不能越过任务替受众作决定。研究项目要求暂定引言和答案，不伪造确定结论。 |
| 本章核心（116） | 问题的结构与引言的可选要素；标题、主张、正文主题和结论相互呼应。词语重复只是提示，实质支持关系仍需检查。 |

### C06：堵车从坏消息变成好消息

位置79—80页/PDF106—107。学生因堵车可能错过考试，见到出题教师也被堵时，预期结果改变，反而获得准备时间。作者以同一条件的不同后果说明：条件本身不足以定义对特定受众的问题。

诊断与修法：若引言只说某现象增加，应补明它造成的具体研究困难或后果；不自动把“变化”判为“问题”。也不据此否认不以个人利害为中心的研究。

### C07：星星数量—宇宙质量—宇宙命运

位置81—83页/PDF108—110。作者串起小问题与更大认识问题，回答“那又怎样”。这是问题意义的教学链条，不是本草案核实过的天文学结论。

诊断与修法：把“研究较少”与“因而不能解释什么”连起来；每一步都需真实关联，不能为了宏大意义硬连到社会发展。

### C08：同为纵酒，安全代价与学校声誉代价不同

位置85—88页/PDF112—115。作者改变问题所付的代价，展示读者价值及拟议方案如何改变；并区分治因、减轻症状及改变人们对代价的感受。

诊断与修法：核查提出的方案解决的是文中所定义的哪一种后果。“改善声誉”不能无声替换为“减少伤亡”。模型不能因某方案更能讨好受众，就替作者改换研究目的。

### C09：奥康纳宗教、种族主义与小说理解

位置89—90、96—100页/PDF116—117、123—127。作者逐步为一个特定作家的解释增加更广的认识后果，并展示共同基础、限制、主张与尾声怎样关联。

诊断与修法：引言的广义意义须能从具体研究延伸；不能只添加“具有重大理论价值”。这些表述是示范论证，文学解释本身仍需文本证据支持。

### C10：网络研究文章里的问题与方案

位置93—94、101—102页/PDF120—121、128—129。达恩顿例子让问题描述预示方案；罗滕伯格例子以说明问题为主体，作者明确指出结尾方案缺少正文支持。

诊断与修法：先看文章承诺是提出问题还是论证方案。若从诊断跳到建议，补充作用机制、可行性和比较理由，或把建议表述为尚待检验的方向；不能要求所有问题诊断文章提交完整政策方案。

## 第四章：找到并陈述一项主张（121—139）

| 小节 | 论证思路、作者强调与修改启示 |
|---|---|
| 对主张展开探讨，别急于下结论（122） | 早提多个可行假说，利用它们找证据；反证应能促使修订。把初始猜测当结论，会把研究变成搜集赞同。 |
| 你的问题需要什么样的主张（123） | 区分理解、行动与隐含行动的价值主张；明确希望读者接受到何种程度。可提供较小的备选方案，但不同强度的主张需各自支持。 |
| 值得考虑的主张的界定（126） | 对具体受众有争议空间；愿意接受可改变想法的理由或证据；实践方案应考虑可行、合宜及副作用。否定测试是识别空泛主张的启发，不是评判所有学术研究的机械算法。 |
| 深思熟虑的主张是什么样的（128） | 概念具体、关系明确、承认例外、判断适度。探索阶段可先写得详细以展开思考，再压缩；不以句子长短或从句数量衡量思考深度。 |
| 写作过程（133） | 追问名词是什么类型、动作如何发生，替换空泛词；检查可能性、频率、数量及证据动词。既防夸大也防过度模糊。 |
| 课后习题（136） | 讨论研究责任、行动与理解的转换，以及对旧稿做反向测试；不能把问题本身当作者结论。 |
| 写作重点（137） | 从相反组织或立场写回应，要求对方也能认可对其立场的描述；用以防止制造假想敌。 |
| 本章核心（138） | 主张回答问题、可修改、有具体内容与恰当限定；积累证据和起草交替进行。 |

### C11：拿锤子的人都看到钉子

位置122—123页/PDF149—150。利润下降时，广告、运营和人事经理都偏好本部门方案。作者要反对的是预先锁定答案，不是证明其中所有方案错误。

修法：提出有差别的解释及可区分它们的证据，记录为何排除备选项。不能将提出多种可能当作已经检验完毕。

### C12：南北战争主张由空泛变具体，再删到适量

位置129—130、134—135页/PDF156—157、161—162。“影响仍存在”经追问影响类型及表现，形成具体概念和关系；过长探索句再删减。

修法：补明究竟是什么影响、体现在哪里，而不是以“复杂性、历史性、结构性”等形容词替代内容。保留最终句中能由正文支持的概念。

### C13：学费与枪支主张的强度

位置130—136页/PDF157—163。学费示例展开条件、原因和让步；枪支例子对比绝对、过度犹豫与较合适的概率措辞。案例用途是说明表述强度，不是提供可用于当前论文的已核实统计。

修法：拆开“结果发生”“发生概率更高”“所有人必然如此”；用研究实际支持的范围措辞。不能根据措辞看起来适中就认定结论可靠。

## 第五章：理由和证据（140—164）

| 小节 | 论证思路、作者强调与修改启示 |
|---|---|
| 支撑主张（140） | 加理由和限定比裸断言周到，但理由也要被证据支持。 |
| 理由和证据是支持的不同形式（141） | 事实、数据和证物只有用于特定支持关系才成为该论证的证据；不等于“一切事实自动相关”。 |
| 区分理由和证据（143） | 理由是判断与组织，证据应能够指明来源、收集方法和局限；不是从头脑里编造材料。 |
| 区分证据和证据报告（144） | 文本通常呈现经过选择、描述、测量或再现的报告；追踪转述链，说明来源和语境。不能由“经过构建”推出所有证据一样主观或一样不可靠。 |
| 多个理由（148） | 并行理由独立支持主张；连续理由逐层支持。并行失败可能剩余支持，连续链丢一环可能断裂。书中避免三个理由的说法属于教学建议，不设为规则。 |
| 用理由帮助读者理解证据（150） | 数据、图像、引文要说明应注意的特征及其意义；理由既支持主张也解释材料。 |
| 写作过程（153） | 理由体现价值和受众；并行项按主题、熟悉度、复杂度、力度组织；连续项按流程或推理顺序，必要时可以逆向。区分直接引用、转述、概述；按研究用途选择。修订时检查数据堆砌或无证据观点。 |
| 课后习题（160） | 办公时间表不等于实际可接触时间；比较原始材料与不同层次的报告；用主张、理由、证据重组教师反馈的三种表述。 |
| 写作重点（161） | 可以学习别人的论证结构，但从吸烟移到饮酒时，要重新检查理由和证据的适用性，不能迁移结论后原样沿用证据。 |
| 本章核心（163） | 来源可追溯、解释证据、组织支持层级；没有固定的证据字数比例或理由数量要求。 |

### C14：恐龙心脏化石的报告链

位置147—148页/PDF174—175。器官→化石→扫描→三维模型→判断，每层都有再现与解释。作者还提示“是否真为心脏”仍可被质疑。

修法：区分观察、处理、推断与转引，指出关键的不确定性；不把“有图、有数据”当作无需说明生成方法。

### C15：油耗表格与哈姆雷特引文

位置150—152页/PDF177—179。前者通过比较与表头解释里程增加而油耗减少；后者解释祷告、灵魂去向与推迟复仇的推理，再引文本。

修法：为图表或引文增加具体的读法及支持关系。解释必须来自材料，不能只写“充分说明了……”或把作者的文学推断冒充引文本身。

### C16：国家测量大学生技能的连续理由

位置149—150页/PDF176—177。从其他国家毕业生数量及能力，经竞争压力，走向教育质量监测建议。作者以此说明多层支持的复杂性及中间台阶不能丢失。

修法：分别检查人数、能力、竞争判断、评估的作用及国家干预原则。数据只支持最后一环时，不能越级宣布整个政策必要性已经证实。

## 应用边界

- 因果、价值和政策主张需要与其类型相称的检验；不能把所有主张按同一实证标准判错。
- 不把本书示例中的历史数据和社会判断移植为当前研究事实。
- 词语重复、证据篇幅、理由数量及主张位置只可辅助定位问题，不能直接给出合格分数。
